# قانون ساده‌سازی اصطلاحات فنی

تمام اصطلاحات فنی باید تا حد امکان به زبان ساده و قابل‌فهم بیان شوند.

## قاعده

معادل فارسی ساده همیشه در اولویت است و اصطلاح انگلیسی فقط در صورت نیاز، داخل پرانتز پس از معادل فارسی نوشته شود.

## نمونه

- درخواست بررسی کد (PR)
- تغییر ثبت‌شده در کد (Commit)
- ساختن نسخه قابل اجرا (Build)
- آزمایش (Test)
- روند خودکار کارها (Workflow)
- آماده‌سازی نسخه نهایی (Release)
- خطا (Bug)
- بررسی (Review)
- مسیر جداگانه برای توسعه (Branch)
- آزمایش و ساخت خودکار (CI/CD)
- گوشی اندرویدی شبیه‌سازی‌شده روی کامپیوتر (Android Emulator)

## ممنوع

استفاده از اصطلاحات انگلیسی فنی به‌صورت مستقل، مبهم یا بدون معادل ساده فارسی؛ مگر در مواردی که نام انگلیسی برای دقت یا اجرای دستور ضروری باشد.

## دامنه اجرا

این قانون برای مستندات، گزارش‌ها، دستورالعمل‌ها، توضیحات کارها و ارتباطات فنی این پروژه لازم‌الاجرا است.
